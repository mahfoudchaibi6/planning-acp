À qui répartir

Temps partiel, absence d'1 jour, formation ou administratif : pas de répartition sur ce créneau le jour même (½ par demi-journée). Absence de 2 jours : pas de répartition la veille ni le 1er jour, répartition le dernier jour. Vacances (3 jours ou plus) : pas de répartition les 2 jours avant le départ ni pendant, répartition le dernier jour. RCP, télétravail et frais médical ne changent rien.

Imprimées sous la grille (ex. « ½ MC = macro »). Ni donnée patient, ni motif d'absence.

Seniors des internes

Un senior différent pour chaque interne, en évitant les absents et en équilibrant les semaines de chacun.

· Seules l'absence et le congrès sont évités : temps partiel, télétravail, formation et administratif ne comptent pas. Entre parenthèses : jours d'absence du senior dans la semaine. Vous pouvez changer un nom à la main puis « Valider ».

Bilan de l'année

Nombre de jours (une demi-journée = 0,5). Sert à équilibrer le frais médical et l'encadrement des internes.

Équipe

Règle du nombre de répartition

Les absences suivent leurs propres règles (1 jour, 2 jours, vacances). Cochez les situations qui retirent le médecin de la répartition le jour même (½ par demi-journée). Réglage partagé par tout le service.

RCP du lundi soir

Changer le code du service

Le planning est rangé sous le code actuel : on le recopie sous le nouveau code, sans rien perdre.

  1. Dans Firebase → Firestore → Règles, remplacez la ligne du code par
    return code == "ANCIEN_CODE" || code == "NOUVEAU_CODE"; puis « Publier ».
  2. Ici, tapez le nouveau code et cliquez sur « Recopier le planning ».
  3. Dans les règles, ne gardez plus que return code == "NOUVEAU_CODE"; puis « Publier ».

💾 Sauvegarde des données

Téléchargez régulièrement une sauvegarde (par exemple chaque mois) et gardez-la sur votre ordinateur. En cas d'erreur, elle permet de tout remettre comme avant.
